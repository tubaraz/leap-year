# Leap Year Calculation Script

## Description

This is a Python script to calculate whether a year is a leap year.

## Requirements

- Python 3.x

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/tubaraz/leap-year.git
   ```
2. Navigate to the project folder:
   ```
   cd leap-year
   ```
3. Run the script:
   ```
   python leap_year.py
   ```
